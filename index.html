Quality Assurance Methodology

1. Understand Review the task requirements and annotation guidelines.
2. Calibrate Establish consistent decisions using examples and project rules.
3. Annotate Apply labels carefully using the available visual evidence.
4. Review Check annotations for errors, omissions, and inconsistencies.
5. Identify Drift Watch for changes in labeling decisions during a batch.
6. Final QA Complete a final consistency and accuracy review before delivery.

Annotation Quality Checklist

  • Does the label match the visible evidence?
  • Does the annotation follow the project guidelines?
  • Is the same rule being applied consistently?
  • Are important objects, actions, or events missing?
  • Are there incorrect or unsupported labels?
  • Is there evidence of label drift?
  • Have ambiguous cases been handled according to the guidelines?
  • Has the dataset received a final quality review?
